# Elephant Peanut Automation

A Python automation project that moves an elephant toward a peanut using conditional logic and a while loop.

## Features

- Automatically determines movement direction.
- Moves one position at a time.
- Stops when the destination is reached.
- Handles cases where the elephant starts at the destination.

## Technologies

- Python 3

## Running the Project

Run the following command from the project directory:

python elephant.py

## Testing

Manually tested three scenarios:

- Moving left from position 9 to 5.
- Moving right from position 2 to 8.
- Starting at the destination (5 to 5).
